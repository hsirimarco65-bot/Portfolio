E-Commerce • 2026

SiriCell – E-Commerce Platform & Management System

Descripción

Plataforma web de comercio electrónico moderna y responsiva desarrollada de extremo a extremo (Full Stack). El sistema resuelve la necesidad de comercialización online mediante una arquitectura desacoplada basada en una API REST y una base de datos NoSQL en la nube.

Código privado: no subido a GitHub por tratarse del desarrollo de un proyecto de negocio propio.

Características Principales

  • Experiencia de Usuario & Catálogo: Navegación fluida de productos con vista detallada, filtrado dinámico y carrito de compras persistente.
  • Proceso de Checkout & Envíos: Módulo de finalización de compra con validación de datos de facturación y cálculo de métodos de entrega.
  • Autenticación y Perfil: Registro e inicio de sesión seguro para clientes, con gestión de perfiles e historial de compras.
  • Panel de Administración (Backoffice): Panel de control protegido para la administración del catálogo de productos, control de stock y seguimiento de órdenes.
  • Arquitectura Backend: API REST modularizada con Express y persistencia escalable en la nube con MongoDB Atlas y Mongoose.

Tecnologías y Herramientas

  • Frontend: JavaScript vanilla moderno (ES6+), HTML5 semántico, CSS3 responsivo (Flexbox/Grid).
  • Backend: Node.js, Express.js (Arquitectura MVC / Rutas modulares).
  • Base de Datos: MongoDB Atlas, Mongoose ODM.
  • Seguridad y Comunicación: Autenticación con JWT / sesiones, CORS y variables de entorno (dotenv).
Backoffice & Pasarela de Pagos • 2026

Gestión de Stock, Ventas y Pagos en Tiempo Real

Descripción

Solución integral de backoffice y checkout automatizado. Conecta directamente la tienda con la base de datos centralizada en MongoDB Atlas para sincronizar inventario al instante tras cada transacción (vía Webhooks de pago y transferencias), brindando a los administradores control total sobre catálogo, métricas de ingresos y estados de envío.

Código privado: no subido a GitHub por tratarse del desarrollo de un proyecto de negocio propio.

Características Principales

  • Pasarela de Pago Integrada: Procesamiento seguro de cobros mediante el SDK de Mercado Pago con soporte para tarjetas, transferencias y dinero en cuenta.
  • Sincronización Inmediata por Webhooks: Recepción y procesamiento de notificaciones de pago (IPN / Webhooks) en tiempo real para confirmar transacciones y actualizar órdenes.
  • Control Automático de Stock: Descuento atómico de unidades vendidas y validación de inventario para evitar sobreventas.
  • Panel Administrativo Integral: Visualización de métricas de ingresos, órdenes en tiempo real y administración completa del catálogo.

Tecnologías y Herramientas

  • Backend: Node.js, Express.js (Controladores modulares y endpoints RESTful).
  • Base de Datos: MongoDB Atlas, Mongoose ODM (Modelado relacional embebido y consultas optimizadas).
  • Pagos & Automatización: Mercado Pago SDK, Webhooks asíncronos y validación de eventos.
  • Seguridad: Autenticación protegida para administradores y manejo seguro de credenciales con dotenv.
Backend Application / CLI • 2025

Sistema de Gestión para Mercado de Abasto

Descripción

Aplicación backend y de consola desarrollada en Java orientada a modelar y resolver la lógica de negocio completa de un mercado de abasto (control de stock, administración de puestos, operaciones comerciales y trazabilidad).

El proyecto fue diseñado priorizando la solidez arquitectónica, separación de responsabilidades y buenas prácticas de desarrollo por sobre la interfaz gráfica, enfocándose en la robustez del modelo de dominio y la confiabilidad del código.

Puntos Fuertes & Aspectos Técnicos

  • Enfoque Core Backend / CLI: Sistema desacoplado de interfaces visuales, listo para ser expuesto mediante una API REST o integrado con persistencia externa.
  • Aseguramiento de Calidad (Testing): Cobertura exhaustiva mediante pruebas unitarias e integración con JUnit, auditadas y validadas mediante métricas de cobertura con JaCoCo.
  • Diseño Orientado a Objetos: Aplicación de principios SOLID, encapsulamiento y patrones de diseño para un código escalable y mantenible (+70 clases).
  • Desarrollo Colaborativo: Trabajo en equipo bajo control de versiones (Git), gestionando resolución de conflictos y asignación modular de tareas.

Tecnologías Utilizadas

Java 21 Gradle JUnit 5 JaCoCo Git Guava

Fashion Style Ruiz – Peluquería & Estética

Descripción

Sitio web comercial desarrollado a medida para el salón de peluquería y estética "Fashion Style Ruiz". El objetivo principal fue crear una vitrina digital atractiva, moderna y ágil que posicione la marca en internet, exhiba los servicios disponibles y simplifique la comunicación con los clientes para reserva de citas y consultas.

Características Principales

  • Diseño Responsive & Mobile-First: Experiencia de usuario optimizada en teléfonos móviles, tablets y pantallas de escritorio.
  • Navegación Interactiva: Menú adaptable con botón hamburguesa desarrollado en JavaScript vanilla, asegurando fluidez y nula sobrecarga de dependencias.
  • Catálogo de Servicios y Trabajos: Exposición clara de especialidades (coloración, balayage, peinados, estética), productos y galería de imágenes.
  • Conversión Directa: Botones de llamada a la acción enlazados directamente a WhatsApp e Instagram para agendar turnos de forma inmediata.
  • Arquitectura Ligera: Código limpio en HTML5 semántico, CSS3 moderno y JavaScript nativo sin dependencias externas innecesarias, con tiempos de carga óptimos.
